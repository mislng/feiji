# TASKS

## State Machine

`BACKLOG → READY → DOING → REVIEW → DONE`

Review failure returns a task to `REWORK` and then `DOING`.

## Task Requirements

Every task should include:
- Goal
- Context
- Scope
- Acceptance criteria
- Constraints / non-goals
- Verification steps

## Active Queue

### BACKLOG
- [ ] Define the first real product/software goal.

### READY
- None.

### DOING
- None.

### REVIEW
- None.

### DONE
- [x] Bootstrap AI team repository instructions.

## Priority Rules

1. Blockers and production-impacting issues.
2. Tasks required by the current milestone.
3. User-facing features.
4. Quality, performance, security, and technical debt.
5. Nice-to-have improvements.
